# MMS系统常用运维命令

## Docker服务管理

### 启动所有服务
```bash
docker-compose up -d
```

### 停止所有服务
```bash
docker-compose down
```

### 重启特定服务
```bash
docker-compose restart backend
docker-compose restart frontend
```

### 查看服务状态
```bash
docker-compose ps
```

### 查看服务日志
```bash
# 查看所有服务日志
docker-compose logs -f

# 查看特定服务日志
docker-compose logs -f backend
docker-compose logs -f frontend
docker-compose logs -f mariadb

# 查看最后50行日志
docker-compose logs backend --tail=50
```

## 代码编译

### 后端编译
```bash
# 完整编译（包含测试）
mvn clean package

# 跳过测试的快速编译
mvn clean package -DskipTests
```

### 前端编译
```bash
cd frontend
npm run build
```

## 重新构建和部署

### 完整重新构建流程
```bash
# 1. 停止服务
docker-compose down

# 2. 编译后端
mvn clean package -DskipTests

# 3. 编译前端
cd frontend
npm run build
cd ..

# 4. 重新构建镜像
docker-compose build --no-cache

# 5. 启动服务
docker-compose up -d
```

### 只重新构建特定服务
```bash
# 只重新构建后端
mvn clean package -DskipTests
docker-compose build --no-cache backend
docker-compose up -d backend

# 只重新构建前端
cd frontend && npm run build && cd ..
docker-compose build --no-cache frontend
docker-compose up -d frontend
```

## 数据库管理

### 连接数据库
```bash
docker exec -it mms-mariadb mariadb -u mms_user -pmms_password mms_db
```

### 执行SQL文件
```bash
docker exec -i mms-mariadb mariadb -u mms_user -pmms_password mms_db < your_script.sql
```

### 执行单条SQL命令
```bash
docker exec -i mms-mariadb mariadb -u mms_user -pmms_password mms_db -e "SELECT COUNT(*) FROM components;"
```

### 备份数据库
```bash
docker exec mms-mariadb mariadb-dump -u mms_user -pmms_password mms_db > backup_$(date +%Y%m%d_%H%M%S).sql
```

### 恢复数据库
```bash
docker exec -i mms-mariadb mariadb -u mms_user -pmms_password mms_db < backup_file.sql
```

### 查看表结构
```bash
docker exec -i mms-mariadb mariadb -u mms_user -pmms_password mms_db -e "DESCRIBE components;"
```

### 查看数据统计
```bash
# 查看组件总数
docker exec -i mms-mariadb mariadb -u mms_user -pmms_password mms_db -e "SELECT COUNT(*) FROM components;"

# 查看active和deleted的组件数量
docker exec -i mms-mariadb mariadb -u mms_user -pmms_password mms_db -e "SELECT status, COUNT(*) FROM components GROUP BY status;"
```

## Redis管理

### 连接Redis
```bash
docker exec -it mms-redis redis-cli
```

### 清空Redis缓存
```bash
docker exec -it mms-redis redis-cli FLUSHALL
```

### 查看缓存键数量
```bash
docker exec -it mms-redis redis-cli DBSIZE
```

### 查看特定模式的键
```bash
docker exec -it mms-redis redis-cli KEYS "components:*"
```

## 容器管理

### 进入容器Shell
```bash
docker exec -it mms-backend sh
docker exec -it mms-frontend sh
docker exec -it mms-mariadb bash
docker exec -it mms-redis sh
```

### 查看容器资源使用
```bash
docker stats mms-backend mms-frontend mms-mariadb mms-redis
```

### 清理未使用的镜像和容器
```bash
# 清理未使用的镜像
docker image prune -a

# 清理未使用的容器
docker container prune

# 清理所有未使用的资源
docker system prune -a --volumes
```

## 日志管理

### 清理日志
```bash
# 清理特定容器的日志
truncate -s 0 $(docker inspect --format='{{.LogPath}}' mms-backend)
```

### 设置日志大小限制
在 docker-compose.yml 中为每个服务添加：
```yaml
logging:
  driver: "json-file"
  options:
    max-size: "10m"
    max-file: "3"
```

## 监控和健康检查

### 查看健康状态
```bash
# 后端健康检查
curl http://localhost:8080/api/actuator/health

# 查看详细健康信息
docker inspect --format='{{.State.Health.Status}}' mms-backend
```

### 监控服务启动
```bash
# 实时查看启动日志
docker-compose logs -f backend frontend
```

## 网络管理

### 查看网络
```bash
docker network ls
docker network inspect mms_decomposor_mms-network
```

### 测试服务间连通性
```bash
# 从后端容器测试数据库连接
docker exec mms-backend nc -zv mariadb 3306

# 从后端容器测试Redis连接
docker exec mms-backend nc -zv redis 6379
```

## 故障排查

### 查看容器详细信息
```bash
docker inspect mms-backend
docker inspect mms-frontend
```

### 查看容器退出码
```bash
docker-compose ps -a
```

### 查看最近的错误日志
```bash
docker-compose logs --tail=100 backend | grep -i error
docker-compose logs --tail=100 backend | grep -i exception
```

### 重启特定服务（保留数据）
```bash
docker-compose restart backend
```

### 完全重建特定服务（不保留容器）
```bash
docker-compose stop backend
docker-compose rm -f backend
docker-compose up -d backend
```

## 性能优化

### 清理Maven缓存
```bash
mvn clean
rm -rf ~/.m2/repository
```

### 清理npm缓存
```bash
cd frontend
npm cache clean --force
rm -rf node_modules
npm install
```

## 安全管理

### 更改数据库密码
1. 修改 docker-compose.yml 中的密码
2. 重建数据库容器
```bash
docker-compose down
docker volume rm mms_decomposor_mariadb_data
docker-compose up -d
```

### 查看敏感信息（小心使用）
```bash
# 查看环境变量
docker exec mms-backend env
```
